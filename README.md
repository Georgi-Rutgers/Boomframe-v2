# Welcome

This is my submission for my Object Oriented Programing course at Rutgers University.

In it, you can find my planning file, where I experimented with calling the API and what would be needed to actually get the data I wanted using requests.

Next, is my text based file, which is where I made my functions for extracting the data from the API, transforming it into more useful statistics like means and medians, as well as removing any outliers. It also loads those stetistics into a graph and prints out the same information in a text format. It unfortunitely is not very user friendly due to the very large amount of items being sold, so choosing an item is not easy even though I made it use numbers to select.

Lastly, is my GUI based version. Using W3 schools, prior experiance, as well as some stack overflow posts about linking Matplotlib with Tkinter, I was able to have a combo box for selecting an item, as well as being able to display both the graph and stats in a single page. I left it really simple and undecorated since the main goal is functionality.

The GUI based version is what I am submitting for grading, and is copied over to a file dubbed FINAL.py which is the exact same as the regular GUI based final with small comment edits.
